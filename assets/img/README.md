# Gambar pengganti

- `profile.svg`: placeholder original, 600 × 800 (3:4). Ganti memakai foto sendiri dalam JPG/WebP, idealnya di bawah 150 KB.
- `project.svg`: placeholder original, 1200 × 750 (16:10). Setiap proyek boleh memiliki file berbeda, idealnya di bawah 200 KB.
- Open Graph: tambahkan JPG/PNG 1200 × 630. SVG kurang didukung layanan pratinjau sosial.
- Letakkan file di folder ini, lalu ubah path dan alt di `../js/data.js`. Path dihitung dari `index.html`, misalnya `assets/img/profile.webp`.
- Hindari spasi dalam nama file. Huruf besar/kecil harus cocok di GitHub Pages.
- SVG di sini dibuat khusus untuk proyek, tanpa foto, logo, atau aset franchise pihak lain.
